## 💡 About The Repository

This repository tracks my journey in developing problem-solving skills through code. It spans basic mathematical operations, user input processing, conditional branching, loops, modular functions, and string sanitization techniques.

**Key Concepts Practiced:**
* Fundamental mathematical calculations and unit conversions.
* Conditional branching (`if-elif-else`) and logic validation.
* Iterative patterns using `for` and `while` loops.
* Functional programming features (Lambda expressions, positional/keyword arguments, `*args`, and recursion).
* String manipulation, parsing, and character counting.
